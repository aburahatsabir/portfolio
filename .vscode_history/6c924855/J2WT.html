System Architecture

The Gated Workflow

We replaced the "honor system" with code. Data cannot physically proceed to the reporting stage without passing a logic gate.

1. Standardization

Raw extracts are dropped into a watching folder. PowerQuery automatically cleans, formats, and flags data type errors immediately before human touch.

The Logic Gate

2. Forced Validation

If Variance > $0 then Lock. The system disables the "Publish" mechanism via VBA ribbon controls until variance explanations are provided.

3. Immutable Output

Upon passing the gate, the system hard-codes values into a PDF with a timestamp watermark and archives it to a read-only network directory.

Under the Hood

The interface simulates the actual VBA logic deployed. The system hooks into the Workbook_BeforeSave event.

I used custom Ribbon XML to disable native Excel features, forcing users through the control buttons. The "Publish" button remains physically disabled (grayed out) until the boolean function CheckGateStatus() returns TRUE.

Module1.bas 
Function CheckGateStatus() As Boolean
    Dim cell As Range
    ' Loop through defined named range
    For Each cell In Range("Control_Range")

        ' Logic Gate: Variance exists AND no comment
        If cell.Value <> 0 And cell.Offset(0, 1).Value = "" Then
            CheckGateStatus = False
            LockDashboard ' Disables Ribbon Buttons
            MsgBox "Variance detected at " & cell.Address
            Exit Function
        End If
    Next cell

    CheckGateStatus = True
    UnlockExport ' Enables PDF Button
End Function
