FMCG Distribution ERP

Zero-cost operational control system for wholesale distribution

Project Overview

Designed and implemented a comprehensive ERP system for a wholesale FMCG distribution network managing 50+ SKUs across multi-state logistics operations.

Impact: Eliminated $12K/year SaaS costs while achieving 99.7% inventory accuracy

The Challenge

The client was operating with fragmented Excel files, manual inventory tracking, and no real-time visibility into stock levels. This resulted in:

  • Frequent stockouts and overstocking situations
  • Manual reconciliation taking 8+ hours weekly
  • No audit trail for inventory movements
  • Inability to track profitability by SKU or region

The Solution

Built a zero-cost ERP system using VBA and advanced Excel with the following components:

  • Inventory Management: Real-time stock tracking with automated reorder points
  • Order Processing: Automated order entry with validation and approval workflows
  • Financial Ledger: Double-entry accounting with automatic GL posting
  • Reporting Dashboard: Executive dashboards with KPIs and trend analysis
  • Audit Trail: Immutable transaction logs with user attribution

Technical Architecture

Technology Stack: VBA, Excel, SQL, Power Query

Data Model: Normalized to 3NF with referential integrity constraints

Integration: API connections to supplier systems and payment gateways

Results

  • 99.7% inventory accuracy (up from 87%)
  • $12,000/year savings from eliminated SaaS subscriptions
  • 8 hours/week time savings on reconciliation
  • Zero data entry errors through validation logic
  • Passed external audit with zero findings
